# 王煜涵个人网站

中英双语个人简历网站，使用 React + Vite 构建，目标部署到 GitHub Pages。

## Local Development

This project needs a JavaScript package manager. Install Node.js LTS first if `npm` is not available.

```bash
npm install
npm run dev
```

## Local Preview

On macOS, double-click `启动网站.command`.

Or run:

```bash
./start-local.sh
```

Then open:

```text
http://127.0.0.1:4173/
```

## Build

```bash
npm run build
```

The static output will be generated in `dist/`.
